1. [Important · Bugs] `app/app.js:87` **Double-clicking a title also ticks or unticks the todo** The title `<span>` sits inside the `<label>` that wraps the checkbox (line 77). In a browser, each click of a double-click activates the label, so the checkbox changes, toggle() runs, the list saves and redraws. Every rename by mouse therefore flips the done state, usually twice, with two saves before the edit box opens. With the 'Chưa xong' filter on, the first click marks the todo done and it vanishes from the view. The second click then lands on whichever row moved into its place: that todo gets toggled, or no edit box opens. A user who only wanted to rename ends up with done states they did not set. (I read the code but did not run it in a browser. To confirm, double-click a title with the 'Chưa xong' filter on and watch `todo.v1`.) → Move the title `<span>` out of the `<label>`, or keep the label to the checkbox alone, so clicks on the title never activate the checkbox. Add an app test that double-clicks with a filter on and checks the done values in `saved` stay the same.
