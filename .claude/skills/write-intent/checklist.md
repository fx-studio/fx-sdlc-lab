# Ready-to-review checklist

Run on the draft before saving. A box passes only if the draft itself shows it.

- [ ] **Problem**: says who is affected and when it happens
- [ ] **Evidence**: at least one concrete item (number, ticket, complaint, screenshot)
- [ ] **Out of scope**: section is present and not empty
- [ ] **Success criteria**: checkable (a number or an observable behaviour), not "better" or "faster"
- [ ] **Open questions**: listed in their own section, each with who can answer, none hidden in the body
- [ ] **Sourced**: every statement in Evidence and Constraints carries a source, and that source really says it

The first five boxes check that something is **there**. Only the last one checks that it is **true**. A fluent draft can pass the
first five with guesses, so never skip the last box.
