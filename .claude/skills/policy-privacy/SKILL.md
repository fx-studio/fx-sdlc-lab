# Privacy policy · v1

Sample policy for the demo. Not legal advice. Each rule has an ID; cite it as `policy-privacy@1#P<n>`.

- **P1.** User data never leaves the user's device without an explicit action by that user. No background upload, no analytics, no
  third-party service.
- **P2.** Anything exported contains only data the user created. No device identifiers, no browser fingerprint.
- **P3.** Exported files are plain and human-readable, so the user can open one and see exactly what is inside.
- **P4.** Tell the user, in plain words inside the app, where their data is kept and what happens when they clear it.
- **P5.** Storing user data anywhere outside the user's browser (server, cloud, account) needs sign-off from the privacy owner first.
