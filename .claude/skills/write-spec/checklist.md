# Spec self-check

A box passes only if the draft itself shows it.

- [ ] **Versions**: line 2 lists every policy skill with the version that was read
- [ ] **Sourced**: every statement outside Assumptions, Concerns and Questions carries a source, and that source really says it
- [ ] **Assumptions**: each line is a yes/no question with who answers
- [ ] **Policies**: every rule that applies is either satisfied under Policy constraints or raised under Concerns
- [ ] **Conflicts**: no conflict between two rules was resolved silently
- [ ] **Scope**: nothing the intent puts out of scope is designed here
- [ ] **Acceptance criteria**: each one is checkable
- [ ] **Carried forward**: every open question of the intent is answered in the spec or listed under Questions carried forward
